Nimbus GitHub

Double-click an Office file. Edit it in Google.

Nimbus is a small Windows app that opens your presentations, documents and spreadsheets in Google Slides, Docs and Sheets, using your own Google Drive.

Download from GitHub Releases Free and open source, for Windows 10 and 11

What happens when you open a file

  1. Nimbus uploads the file to a Nimbus folder in your Google Drive.
  2. Google converts it to its own format, so every editing feature works.
  3. The file opens in your browser, ready to edit.

Supported files

Opens inFile types
Google Slidesppt, pptx, odp
Google Docsdoc, docx, odt, rtf
Google Sheetsxls, xlsx, ods, csv

No duplicates

If you open a file again and it hasn't changed, Nimbus opens the Google copy you already have. If you've changed it, Nimbus uploads a new copy.

Your files stay yours

Files go straight from your PC to your own Drive. Nimbus has no server and sends nothing to its developer. It can only see the files it created, not the rest of your Drive.
